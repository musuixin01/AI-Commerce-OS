## 品牌与设计语言

品牌气质：专业、沉稳、可信、可追溯的电商工作台。采用中性色面板、清晰的状态色和少量品牌强调色；操作风险优先于装饰。Web/Windows/macOS 承担复杂运营，iOS/Android App 优先拍照建档、审批、客服与异常提醒。统一 8px 间距节奏、明确字体层级、可读数据密度；响应式导航、不依赖颜色单独表达状态。组件需支持键盘、焦点可见、屏幕阅读器和中英文字段扩展。

## 体验原则与信息架构

- AI 助手为默认主区：用户上传图片或输入目标，查看任务步骤、成果预览并确认执行。待处理/异常/已完成作为任务卡辅助；来源、版本和执行范围可展开。
- 草稿、待批准、执行中、平台成功、平台拒绝、需人工处理均为独立状态；对不可逆操作显示目标店铺、字段差异、费用和审批人。
- 一级导航：工作台 / 商品中心 / 客服中心 / 市场中心 / 数据中心 / 店铺中心。知识库、工作流、模型与 MCP 收纳到高级能力/设置，审批与发布历史保持可达。组织/店铺上下文可见；详见 AI_EMPLOYEE_PRODUCT。

数据中心独立展示店铺经营指标与报告；市场中心负责有许可的市场/竞品/选品数据；店铺中心负责连接、同步、自动化规则和预算。六中心均可打开带当前对象上下文的统一 AI 助手。详细布局与成果规则以 AI_EMPLOYEE_PRODUCT 为准。

## 跨平台布局

Web 与桌面共享 ui-web；手机使用 ui-native，设计 token 共用。macOS 菜单/快捷键、Windows 窗口/缩放、iOS 安全区/返回手势与 Android 返回键分别设计；平台差异不通过压缩 PC 页面解决。详见 CROSS_PLATFORM_ARCHITECTURE。

## 状态、错误与设计验收

空态提供下一步；加载态显示来源和时间；外部平台失败保持本地任务且提供可重试的原因；网络断开不重复提交。草稿默认可撤销，发布前以二次确认绑定店铺和版本。每页设计验收含桌面/手机布局、键盘路径、无障碍标签、空/错/加载态，以及权限不同角色的可见性。视觉稿与可用性测试在界面编码前单独评审。
