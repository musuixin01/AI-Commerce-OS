状态：开发设计基线；上线前需专项审查。资产：组织商品、客户数据、连接器令牌、知识原件、模型上下文、执行日志与审计。攻击面：Web/API、MCP、文件上传、平台 webhook、第三方模型、外部文档与插件。

| --- | --- | --- |

认证可采用 OIDC；Session 短期有效，服务端撤权；多因素要求在上线策略中确定。租户数据驻留区域按合同与平台要求配置，供应商数据处理条款和跨境传输在接入前核实。MCP 工具只走 Backend API，禁止 MCP 直接数据库访问。密钥不得出现在仓库、测试夹具、提示词或模型日志。

## 后台 AI 执行恢复（ADR-014）

AI attempt 使用短租约和内部 lease token；浏览器响应不返回 lease token 或 provider request_key。真正外部调用前通过 prepareExternalCall 原子记录 Provider/Model、费用预留并再次检查创建者 Membership。若租约在此前过期，可证明未跨外部边界并按已知失败安全重试；跨过该边界后的进程崩溃、租约超时或供应商结果不可确认必须进入 UNKNOWN，并保留预算预留，只有查询供应商回执或其他明确证据完成 reconciliation 后才允许判定成功/失败。禁止“外部结果不明即重试”，避免重复费用、重复成果及未来副作用重放。

Artifact 固定输入版本、摘要、attempt、Provider/Model 与来源；追加新版本，不覆盖旧成果。当前 E1-01b 不调用真实模型，真实 Provider 凭据仍不得进入数据库成果、浏览器响应、测试夹具或日志。

## 安全门槛

MVP 上线须完成威胁模型评审、隔离测试、恢复演练、外部 API 访问审计、敏感数据清单和事件响应联系人。初始事件流程：发现→限制写入/撤销密钥→保留证据→评估影响→按合同及适用法律通知→复盘；具体时限由合规评估确定。
