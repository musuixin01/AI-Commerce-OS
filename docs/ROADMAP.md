# ROADMAP — 3–5 年方向与退出条件

状态：方向性计划，非交付日期承诺。阶段按可测门槛推进，技术分拆依据数据量/故障/团队需求，而非时间。

| 阶段 | 能力 | 进入/退出证据 |
| --- | --- | --- |
| 0 设计与试点 | 基线文档、用户访谈、平台可行性 | MVP 范围与责任人确认 |
| 1 受控 MVP | 五端最小可安装/可访问闭环、基座、知识、AI、商品、审批、Mock/条件真实平台、只读 MCP | 真实用户完成闭环，安全硬门槛通过 |
| 2 商业 SaaS | 自助租户、计量、计费、监控、客服平台接入 | 可恢复、成本可控、付费意愿证实 |
| 3 生态 | 多平台写入、开放 API/MCP、扩展工具、行业模板 | 每个平台有能力/权限矩阵及兼容测试 |
| 4 规模与企业 | 多区域、企业治理、SLO、独立可扩容组件 | 性能、成本、组织需求证明拆分合理 |

每季度评审阶段成果、真实使用与成本，调整排序；任何阶段都不能省略权限、审计与数据隔离。
