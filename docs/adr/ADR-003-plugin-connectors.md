# ADR-003 — 平台连接器能力接口

状态：Proposed；日期：2026-09-28。

## 背景与问题

拼多多、淘宝/天猫、京东等平台授权、字段、审核、频率限制不同；直接把平台 SDK 写入商品领域会形成强耦合。

## 方案与选择

A：核心业务直接调用平台 SDK。B：标准商品模型 + 版本化 adapter 能力矩阵（读取、预检、发布、回执、订单同步）+ 平台字段映射。C：公共爬取层。**选择 B 作为首选提案**，只启用已获官方授权的能力。

## 影响与验证

按平台/店铺记录授权范围，连接器声明其可用能力、限流和映射版本；同步数据保留来源与时间。首个平台必须先核验官方准入/测试环境/发布审核；能力不可用时标记不支持，不能静默模拟成功。
