# ADR-002 — 独立 MCP 协议边界

状态：Proposed；日期：2026-09-28。

## 背景与问题

外部支持 MCP 的 AI 客户端需要调用商务能力，但公开工具不得绕过已有 API 权限和人工审批。

## 方案与选择

A：每客户端定制插件。B：独立 MCP Server 仅做协议/会话/作用域适配，调用统一 Backend API。C：让 MCP 直接读写数据库。**选择 B 作为首选提案**：最小工具集合从只读起步，写入按资源/店铺授权并共用审批。

## 影响与验证

实现前核实目标客户端实际 MCP 支持、认证方式及网络部署；无支持时提供同权限的开发者 API。进行越权、重放、撤销令牌和审批绕过测试；绝不假定 ChatGPT 等客户端均可直接接入任意服务器。
