# ADR-001 — 单 AI 核心，多岗位配置

状态：Proposed；日期：2026-09-28。

## 背景与问题

运营、客服、市场分析需要不同流程与知识。若每个岗位独立构建模型系统，权限、成本与审计易分裂；若仅一段大提示词，可靠性和任务边界不足。

## 方案与选择

A：每岗位独立模型/服务。B：单一 LLM Provider Layer + 各岗位版本化策略（提示、知识作用域、工具白名单、预算、审批）+ 工作流编排。C：完全通用聊天代理。**选择 B 作为首选提案**：模型可以按任务路由，统一身份、调用记录及成本。这里“单核心”不等于只能使用一个模型供应商。

## 影响与验证

岗位配置版本固定到每次执行；跨岗位知识和工具禁止自动继承。以商品草稿、客服建议、市场报告各一条流程验证成本、准确率和越权防护。Gate 0 确认后更新为 Accepted。
