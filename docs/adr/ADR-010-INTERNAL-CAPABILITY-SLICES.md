# ADR-010 — 内部功能分片及 AI 接口

状态：Accepted，2026-09-28；承接用户持续实现授权。正式 OIDC、五端签名与店铺权限仍是上线门槛，开发环境使用回环网络限定的样例身份继续独立业务验证。

本片先实现文本知识资料：内容不可变、版本与 SHA 固定、负责人发布、组织/空间过滤。大文件上传、对象存储及向量嵌入待下一片；当前查询为文本匹配，不能标作向量检索。

AI 使用统一 Provider 接口，首个适配器为 OpenAI Responses 结构化输出；模型由环境配置指定，不硬编码高价型号。商品/客服岗位共享核心且不提供外部写工具。请求最多 6000 字问题、10 份资料、总来源 20000 字、1500 输出 token；组织每日最多 20 次尝试。请求先持久化并按请求键去重，供应商超时/崩溃结果保留 UNKNOWN/RUNNING，不自动重新付费调用。来源 ID 和引文需与授权资料逐项核对；生成文本仍由人工核验。无配置则 503，无资料则 422。

官方依据：https://developers.openai.com/api/docs/guides/structured-outputs （2026-09-28 核对）。适配器测试采用注入的本地测试 provider，不能当作真实模型质量评测。
