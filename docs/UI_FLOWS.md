# UI_FLOWS — AI 员工主入口与业务任务流

状态：v2 主交互见 [AI_EMPLOYEE_PRODUCT](AI_EMPLOYEE_PRODUCT.md)，下表保留业务模块结构供实现；颜色/字体/细节视觉稿仍需评审。统一顶栏：组织、工作区、店铺、全局搜索、预算/通知与个人菜单。左侧导航对应 UI_UX_DESIGN，所有页面在右侧可打开证据/审计侧栏。

| 页面 | 主区域从上到下 | 右侧/底部辅助 | 主要操作与返回 |
| --- | --- | --- | --- |
| AI Dashboard | AI 任务输入/图片上传；常用目标；成果预览与执行步骤；最近任务 | 工作流快捷入口、AI 建议引用 | 选择任务→预估成本→启动→查看执行→回审批 |
| 商品中心 | 搜索筛选/表格；商品详情基本信息/图片/SKU/适配；平台对照和预检 | 资料来源、版本差异、审批时间线 | 上传→字段提取→逐项确认→预检→提交审批→查看发布回执 |
| 客服中心 | 会话/工单列表；消息历史；建议编辑器 | 订单摘要、知识引用/版本、风险提示 | 选择会话→查看 AI 自动回复和回执→必要时人工接管；自动发送需店铺规则授权 |
| 市场分析中心 | 指标/时间/店铺筛选；数据图表；结论卡 | 数据源、口径与延迟、导出 | 选择授权数据→计算/AI 总结→查证→保存报告 |
| 工作流编辑器 | 模板目录；节点画布；执行历史 | 节点属性、scope/预算、模拟结果 | 编辑→静态验证→Mock 模拟→版本发布→运行 |
| 知识库管理 | 库列表；文档上传/状态/版本；检索测试 | 解析错误、引用去向、权限 | 上传→解析预览→纠错→审批发布→检索验证 |
| MCP 管理中心 | 客户端列表/状态；scope/工具清单；调用日志 | 风险级、令牌撤销与测试结果 | 创建受限接入→测试只读→查看审计→撤销 |
| 系统设置 | 成员/权限、组织/空间/店铺、模型/预算、连接、审计 | 配置差异与影响范围 | 编辑→预览影响→确认→生成审计→可用时回滚 |

移动端指 iOS/Android 正式 App，桌面指 Web/Windows/macOS。商品移动端：先列表/审批卡，详情按“参数、SKU、来源、发布”分屏；复杂表格采用卡片。客服移动端：会话与建议分层，底部固定回复/接管控制，清晰显示自动接待状态。工作流移动端仅查看状态/审批，不开放节点拖拽编辑。所有提交按钮在 pending 时禁止重复触发，错误留在页面；无权限显示原因与申请途径，不展示敏感内容。页面间 deep link 保留组织/空间上下文但服务端重新鉴权。

新版主路径：工作台上传商品图→AI 图文/字段成果→一次补齐缺项→用户审阅确认→授权平台发布/回执；选择已发布商品→诊断→变更集→确认更新。旧表单/审批入口保留。新增数据/店铺中心按 AI_EMPLOYEE_PRODUCT 实施。

## 三条可点击路径验收

1. 商品：商品列表→上传→字段/适配核验→平台预检→审批详情→发布/人工导出→回执详情；每一步可返回，版本变化提醒审批失效。
2. 客服：平台新消息→规则/知识校验→自动回复或转人工→实际送达状态→可查看引用和审计；辅助模式人工确认；接管立即阻断待发自动回复。
3. 工作流：模板→节点配置→权限/预算预检→模拟运行→发布版本→执行详情→审批等待→结束/人工恢复。
