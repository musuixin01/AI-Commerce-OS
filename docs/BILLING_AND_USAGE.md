# BILLING_AND_USAGE — 计量与订阅草案

状态：后续商业能力的设计预留，不作为 MVP 支付实现。Organization 对应账单账户；计划定义席位、店铺、存储、工作流和模型预算。UsageEvent 保存租户、来源、用量单位、价格版本、币种、估算与最终结算区分、去重键与时间。模型成本同时记录供应商回执与内部估算；差异可追踪。

预算控制在任务接收前预留估算额，完成后调整，失败释放；并发计量用事件去重和聚合快照，不能由可变仪表盘数直接开票。到达硬上限停止新 AI 任务，必要的人工/查询能力继续运行。开通付费前完成支付服务商选择、发票税务、退款规则、计费争议处理和数据驻留审查。

E1-01b 先实现任务级预算护栏：AgentTask 使用 currency + amount_micros 整数（1/1,000,000 货币单位）记录最大预算、已用与预留；外部调用前 reserve，已知结果按实际成本结算。UNKNOWN 保留预留直到供应商结果对账，避免未知结果时再次消费。该字段是执行安全证据，不是最终账单或 UsageEvent 商业结算实现。
