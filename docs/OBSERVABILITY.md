# OBSERVABILITY — 指标与诊断

状态：开发设计基线。每个请求和异步运行贯穿 trace_id、organization_id（仅内部安全日志）、workflow_run_id、operation_id；PII、密钥和全文提示不进普通日志。

| 维度 | 必须观测项 | 行动 |
| --- | --- | --- |
| API | 请求量、状态码、延迟分位、鉴权拒绝 | 关联 trace 与服务 |
| Workflow | 队列等待、节点耗时、重试、UNKNOWN、死信 | 看卡住节点，安全人工恢复 |
| Connector | 授权健康、平台限流、发布/审核结果、同步滞后 | 自动暂停失效连接 |
| AI | 模型、任务、token、估算费用、超时、结构化失败 | 租户预算告警和熔断 |
| Knowledge | 解析失败、索引落后、检索空结果、权限拒绝 | 重建索引/更新资料 |
| Security | 越权尝试、令牌撤销、异常发布频率 | 事件响应与锁定 |

上线前定义 SLI/SLO：月可用性、API 延迟、任务完成时间、数据新鲜度、发布操作 UNKNOWN 时长；目标值经试点负载和商业承诺确定。告警必须有 owner、严重级、排障链接和静默规则。审计记录另存，append-only，普通运营日志过期删除；留存和告警成本按组织与地域策略执行。
